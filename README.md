# Fact Hunter · Баримт Анчин

**MILHACK 2026-ийн 2 дахь санаа** — хуурамч мэдээлэл таних мөрдөн шалгах вэб тоглоом (Хэвлэлийн Хүрээлэн + EAVI).

Тоглогч шинэ мөрдөгч **Мийку** болж, ахлах редактор **Галаа**-гийн даалгавраар Facebook постуудыг өөрөө судалж, хайлт хийж, нотолгоо цуглуулаад пост бүрийг **Үнэн / Худал / Баталгаагүй** гэж дүгнэнэ.

> Нягтал. Эргэлз. Хамгаал.

Ижил хакатоны нөгөө тоглоом: [swipe-smart](https://github.com/50iinchiher/swipe-smart) (Өдрийн 5).

## Ажиллуулах
Цэвэр HTML + CSS + JS — framework, build хэрэггүй. `index.html`-ийг хөтөч дээр нээхэд л ажиллана.

## Бүтэц
- `index.html`, `css/style.css`
- `js/` — `state.js`, `screens.js`, `investigate.js`, `main.js`
- `data/cases.js` — бүх контент
- `assets/` — Галаа, Мийку дүрс
